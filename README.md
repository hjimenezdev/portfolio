# Hugo Jiménez — Portfolio

Portfolio personal de **Hugo Jiménez Muñoz**, Desarrollador Web Frontend. Diseño dark minimalista con detalles en morado, completamente bilingüe (ES/EN) y desplegable como sitio estático.

---

## 🚀 Demo

🔗 [hjimenezdev.vercel.app](https://hjimenezdev.vercel.app)

---

## 📁 Estructura del proyecto

```
portfolio/
├── index.html     # Estructura HTML y contenido
├── styles.css     # Estilos, variables, animaciones y responsive
├── main.js        # Lógica: cursor, scroll, idioma, formulario y skills
└── README.md
```

---

## ✨ Características

- **Dark mode** con paleta oscura (`#0D0D12`) y acentos en morado (`#8B5CF6`)
- **Bilingüe ES/EN** — toggle en la navbar, sin recarga de página
- **Cursor personalizado** con anillo reactivo al hover
- **Animaciones de entrada** con `IntersectionObserver` (scroll reveal)
- **Marquee animado** con el stack tecnológico
- **Skills con iconos oficiales** via [Simple Icons CDN](https://simpleicons.org)
- **Hover en experiencia** con transición lenta y simétrica (1s `ease-in-out`)
- **Formulario de contacto** con feedback visual al enviar
- **Diseño responsive** adaptado a móvil desde 900px

## 🎨 Stack de diseño

| Recurso | Uso |
|---|---|
| [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) | Tipografía display (títulos) |
| [DM Mono](https://fonts.google.com/specimen/DM+Mono) | Tipografía monoespaciada (etiquetas, nav) |
| [Outfit](https://fonts.google.com/specimen/Outfit) | Tipografía cuerpo |
| [Simple Icons](https://simpleicons.org) | Iconos de tecnologías en color oficial |

## 🛠️ Tecnologías del portfolio

- HTML5 semántico

## 📦 Despliegue

El proyecto es un sitio estático puro. Compatible con cualquier plataforma de hosting estático.

### Local

```bash
# Clona el repositorio
git clone https://github.com/hjimenezdev/portfolio.git

# Entra en la carpeta
cd portfolio

# Abre con cualquier servidor local, por ejemplo:
npx serve .
# o simplemente abre index.html en el navegador
```
